One pickup line, in the voice of a robot trying to charm someone, for the
[make.fun bounty](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

> I don't have a heart, but my battery drains 40% faster whenever you smile.

## Run

```sh
python3 main.py
```

Writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
